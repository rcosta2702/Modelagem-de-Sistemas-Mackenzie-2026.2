# Constituição do projeto

1. Usar Python 3.14+ e pytest.
2. A fonte de verdade é specs/checkout_frete.md. Alterar a especificação antes dos testes e do código.
3. Executar uma tarefa por vez e registrar os resultados reais Red/Green.
4. Manter funções simples, sem rede, persistência, cupons ou dependências externas de execução.
5. Usar Decimal para valores monetários e referenciar os requisitos em código e testes.
6. Versionar especificação, implementação e testes da mudança no mesmo commit.
